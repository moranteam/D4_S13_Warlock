## How to Read This File

The 13 milestone rows below capture the full leveling-through-endgame progression of the active skill bar for a Dread Claws Mastermind Warlock on PS5.

**Bar contents** (which skills are on the bar at each milestone) are canonical from Maxroll. **HIGH confidence.**

**Button placement** is the pure Maxroll ergonomic layout per Resolution 5: the spam Core (Dread Claws) lives on R2 from Lv 3 forward, never moving. The two endgame swaps (Hellion Sting to Command Fallen at Lv 34, Command Fallen to Profane Sentinel at Final Endgame) both happen on Square so the player feels the build's identity shifts on the same physical button. **HIGH confidence on the layout pattern, MEDIUM on the specific button choices because button placement is player preference.**

Sprint 3 will add per-user button customization. Until then, this file is the recommended default. Two valid alternative layouts are documented at the bottom for reference.

## Layout Pattern (Locked Slots)

These slots stay constant once their skill unlocks. The player never moves the skill off the button.

| Button | Skill | Unlock Level | Why this button |
|---|---|---|---|
| R2 | Dread Claws | Lv 3 | Spam Core. R2 is the trigger that fires continuously from Lv 3 to Lv 70. Right index finger fluency. |
| R1 | Rampage | Lv 8 | Greater Demon recast button. R1 is the natural index-finger trigger for repeated casts that apply Hex via Blasphemous Fragment from Lv 30 onward. |
| Circle | Nether Step | Lv 4 | Mobility on the right thumb for instinctive evade chaining and Shadowform generation. Becomes Evade itself once Footfalls of the Waning World is equipped. |
| X | Summon Laalish | Lv 15 | Soul Shard active. Thumb access for the Mastermind Shard's signature ability. |
| Triangle | Ultimate slot (Metamorphosis from Lv 41 onward; Dark Prison Lv 34 to 40 placeholder; Sigil of Subversion Lv 15 to 34 placeholder) | various | Triangle is the "swap slot" the player learns to associate with build identity shifts. Settles on Metamorphosis as the Ultimate from Lv 41. |
| Square | Resource slot (Hellion Sting Lv 8 to 34 placeholder; Command Fallen Lv 34 to 70; Profane Sentinel Final Endgame) | various | Square holds the resource-generation skill. The Lv 34 swap (Hellion Sting to Command Fallen) and the Final Endgame swap (Command Fallen to Profane Sentinel) are the two build-defining identity shifts in this build, both felt on Square. |
| L2 | Evade by default; Sigil of Summons in Final Endgame boss fights once Footfalls equipped frees the slot | n/a | D4 PS5 default. |

## PS5 Layout Reference

D4 on PS5 uses 6 active skill slots plus Evade plus Potion:

| Button | Default Use |
|---|---|
| Square | Active skill slot 1 |
| Triangle | Active skill slot 2 |
| Circle | Active skill slot 3 |
| X | Active skill slot 4 |
| R1 | Active skill slot 5 |
| R2 | Active skill slot 6 |
| L1 | Potion |
| L2 | Evade (default) or seasonal mechanic depending on config |

Skills can be freely reassigned in Settings then Controls then Controller then Skill Assignment (press L3 while in the skill tree).

## Sprint 3 Customization Caveat

Bar contents in this file are canonical Maxroll and should not be customized in the app: those are the build's mechanical requirements. Button placement is player preference and **will be customizable in Sprint 3** through a per-user override layer in the Gear Comparison module (or wherever the Sprint 3 spec lands the customization UI).

The defaults shown here are the pure Maxroll ergonomic layout. Two alternative layouts that respect the same bar contents:

- **Charlie's current pre-Sprint-1 layout.** Dread Claws on Square (Charlie's existing muscle memory), Nether Step on Triangle, Metamorphosis on Circle. Trade-off: keeps existing fluency but loses the R2-is-spam-trigger convention and the Triangle-is-Ultimate convention that most Diablo controller guides recommend. The Sprint 3 customization UI will let Charlie pin this layout if preferred.
- **R2 as the resource swap slot.** Command Fallen then Profane Sentinel on R2, Dread Claws on Square. Trade-off: the build's identity shift is felt on the trigger button, but the spam Core moves to a face button which some players find slower for sustained-fire fluency. Valid for players who want the Lv 34 and Final Endgame swaps to be the most physical part of the layout.

The Sprint 3 UI will let the player slot any skill into any button without breaking the build mechanics.
